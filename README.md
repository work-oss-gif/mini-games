# Meadowbrook Farm (3D)

An original 3D farming game for Android. Plant crops, raise animals, fill delivery orders and grow your farm.

- The game is `app/src/main/assets/index.html`, drawn in 3D with three.js (bundled, so no internet needed).
- `MainActivity.java` just shows that page full screen.
- The APK is built by GitHub Actions on every push: open the run, scroll to **Artifacts**, download the zip and install `app-debug.apk`.
